# Official Document Checklist

## Identity
- [ ] Valid passport
- [ ] Birth certificate
- [ ] National ID if required
- [ ] Passport photos if required

## Education
- [ ] Final secondary/vocational certificate
- [ ] Full transcript / marks statement
- [ ] Diploma or technical certificate if applicable
- [ ] Grading-scale explanation if required
- [ ] Certified English translation
- [ ] Legalisation / authentication / apostille if required

## Admission and scholarship
- [ ] University application
- [ ] Scholarship application
- [ ] CV
- [ ] Motivation / personal statement
- [ ] Recommendation letters if required
- [ ] Academic references if required
- [ ] English proof if required
- [ ] Entrance/aptitude test if required

## Visa and arrival
- [ ] Offer/scholarship letter
- [ ] Visa application
- [ ] Medical examination if required
- [ ] Police/security clearance if required
- [ ] Accommodation evidence if required
- [ ] Insurance if required
- [ ] Flight/travel document

Every document needs an issuer, correct name/date, clear scan, translation status, certification status, destination requirement, source URL, and verification date.
